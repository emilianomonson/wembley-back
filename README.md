# ⚽ Wembley Utilería - Backend API

Este es el motor de **Wembley Utilería**, un negocio real de equipamiento deportivo en Río Tercero, Córdoba. Se encarga de la gestión de stock, categorías y administración de productos.

## 🛠️ Tecnologías
* **Java 17+**
* **Spring Boot** (Framework principal)
* **JDBC** (Persistencia de datos)
* **SQL Server** (Base de Datos)

## 🔐 Seguridad
El proyecto utiliza **variables de entorno** para proteger las credenciales de la base de datos, asegurando que los datos sensibles no se filtren en el repositorio.

## 🚀 Funcionalidades
* CRUD completo de productos.
* Gestión de categorías (Botines, Zapatillas, Ropa, Utilería).
* Control de stock por talle.
